# Sales Performance Analysis

## Project Overview

This project is a Data Analytics project developed using Microsoft Excel, SQL, and Power BI.

The project analyzes sales data to understand sales performance, category-wise and region-wise trends, and key business metrics. The analysis was performed using Excel and SQL, followed by dashboard development in Excel and Power BI.

## Objectives

* Analyze sales data and identify important trends.
* Perform data analysis using Excel and SQL.
* Calculate important Key Performance Indicators (KPIs).
* Create a dashboard using Excel.
* Create an interactive Sales Performance Dashboard using Power BI.
* Present sales information through clear and meaningful visualizations.
